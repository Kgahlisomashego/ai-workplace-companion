# AI Workplace Companion

Build a modern, responsive SaaS-style web application called “AI Workplace Productivity Assistant”.

The app should help professionals complete common workplace tasks using AI. Keep the design clean, modern, professional, and easy to use, using a navy blue and light color palette.

Core Features

1. Smart Email Generator

Generate professional workplace emails.

Allow users to select a tone: Formal, Friendly, or Persuasive.

Provide structured input fields for the email purpose, recipient/context, and key points.

Display the generated email in an editable output area so users can modify it before copying.

2. AI Research Assistant

Allow users to enter a topic, question, or article text.

Generate clear summaries.

Provide key insights, important points, and practical recommendations.

Present results in an easy-to-read format.

3. AI Workplace Chatbot

Include a modern conversational AI interface.

Users can enter workplace-related prompts and receive AI-generated responses.

Include example prompts to help users get started.

Display conversations clearly in a professional chat layout.

UI/UX

Create a modern dashboard interface with:

Left sidebar navigation on desktop.

Responsive mobile navigation.

Dashboard/home page with an overview of the available AI tools.

Separate pages or sections for Email Generator, Research Assistant, and AI Chatbot.

Modern cards, buttons, input fields, text areas, icons, and subtle animations.

Clear input and output sections.

Editable AI-generated results.

Copy-to-clipboard buttons where useful.

Loading states and friendly empty states.

Fully responsive design for desktop, tablet, and mobile.

Important Technical Constraints

This is a frontend-only prototype.

Do NOT create a backend.

Do NOT add a database.

Do NOT require users to log in or register.

No authentication system.

No user accounts.

Do not build unnecessary server-side infrastructure.

Keep the application simple and suitable for building with a free Lovable account.

Use realistic mock/demo AI responses if a real AI API cannot be used.

Structure the UI so that a real AI API could potentially be connected later.

Responsible AI

Include a visible but unobtrusive disclaimer explaining that AI-generated content may contain mistakes and should be reviewed by the user before being used for important workplace decisions or communication.

Overall Goal

Make the application feel like a real professional SaaS productivity platform, not a basic school project. Prioritize simplicity, usability, clean spacing, professional typography, responsive design, and a polished navy-blue/light visual identity.

The final application should work as a no-login, frontend-only AI workplace productivity demo that users can immediately open and use.
